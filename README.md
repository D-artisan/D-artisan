#### 02 / Distributed systems & reliability

**[HotelStream Reliability Lab ↗](https://github.com/D-artisan/trivago-sre-lab)**

`Kubernetes` `Kafka` `KEDA` `Redis` `Python`

<details>

- A Redis read model fed by hotel-price events.
